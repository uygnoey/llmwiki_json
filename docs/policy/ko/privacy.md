- 시행일: {{EFFECTIVE_DATE}}
- 개인정보 처리자: {{OPERATOR}}
- 문의: {{CONTACT}}

> 초안입니다. 서비스를 실제로 개시하기 전에 법률 검토를 받아야 합니다.

## 1. 수집하는 항목

| 구분 | 항목 | 근거 |
|---|---|---|
| 계정 | 식별자, 이메일, 표시 이름 | 계약 이행 |
| 그룹 | 소속 그룹, 역할, 가입 시각 | 계약 이행 |
| 문서 | 문서·블록의 `authors`, `history`, `created`·`updated` | 계약 이행 |
| 접근 | 접속 시각, 요청 경로, IP, 사용자 에이전트 | 정당한 이익(보안) |
| 초대 | 초대 토큰의 해시, 만료 시각, 사용 횟수 | 계약 이행 |

문서 본문은 이용자가 직접 작성한 것으로, 이용자가 넣지 않는 한 개인정보를 포함하지
않습니다. 본문에 제3자의 개인정보를 넣지 마십시오.

## 2. 이용 목적

1. 위키 저장·색인·검색·그래프 표시 등 서비스 기능 제공
2. 그룹 권한 판정과 접근 제어
3. 문서 기여 이력 표시 및 탈퇴 시 삭제 대상 판정
4. 장애 대응, 부정 이용 방지, 보안 사고 조사

## 3. 저장 위치와 보관 기간

1. 정본 문서와 파생물은 객체 스토리지({{STORAGE_PROVIDER}}, 리전 {{REGION}})에
   저장됩니다.
2. 계정·그룹·권한 정보는 별도 데이터베이스에 저장됩니다.
3. 보관 기간
   - 계정 정보: 탈퇴 시까지
   - 문서: 탈퇴 시 이용자가 선택한 처리 방식에 따름
   - 접근 로그: {{LOG_RETENTION_DAYS}}일
   - 삭제 표식(tombstone): 무기한 (개인정보를 포함하지 않음)

## 4. 제3자 제공과 처리 위탁

1. 법령에 따른 요구가 있는 경우를 제외하고 제3자에게 제공하지 않습니다.
2. 인프라 운영을 위해 다음에 처리를 위탁합니다: {{SUBPROCESSORS}}.
3. 다른 이용자에게 문서가 보이는 것은 "제3자 제공"이 아니라, 이용자가 선택한
   **공유 설정의 결과**입니다.

## 5. 탈퇴 시 처리

탈퇴 시 계정 정보는 지체 없이 삭제합니다. 문서는 이용자가 **전체 삭제** 또는
**그룹으로 소유권 이전 후 유지** 중 하나를 선택합니다. 삭제를 선택하더라도
기술적으로 되돌릴 수 없는 부분이 있습니다. 상세와 그 한계는
[공유·재사용 및 탈퇴 동의](sharing-and-deletion.md)에 정리되어 있습니다.

## 6. 이용자의 권리

열람, 정정, 삭제, 처리 정지, 데이터 이동을 요청할 수 있습니다. 데이터 이동은
JSON 정본 전체를 내려받는 형태로 제공합니다. 요청은 {{CONTACT}} 으로 하시면
{{RESPONSE_DAYS}}일 이내에 처리합니다.

## 7. 보안 조치

1. 전송 구간 암호화(TLS) 및 저장 시 암호화
2. 사전 서명 URL(presigned URL) 사용, 짧은 만료 시간 적용
3. 초대 토큰은 해시만 저장하며 원문을 보관하지 않음
4. 비공개 그룹 문서의 격리 규칙을 빌드 단계에서 강제
5. 권한 판정은 스토리지 ACL 이 아니라 별도 권한 데이터베이스에서 수행
