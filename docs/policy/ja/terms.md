## 1. サービスの概要

本サービス（以下「本サービス」）は、利用者が作成した知識文書を JSON 正本として保管し、
グループ単位で共有し、複数グループの文書を組み合わせて閲覧できるようにする共有ウィキです。
文書はオブジェクトストレージに保存され、派生物（索引・グラフ）は正本から再生成されます。

## 2. アカウントとグループ

1. 利用者はアカウントを作成し、一つ以上のグループに所属できます。
2. グループは **公開（public）** または **非公開（private）** に設定されます。
   - 公開グループの文書は本サービスの利用者が閲覧できます。
   - 非公開グループの文書は構成員のみが閲覧でき、外部文書の参照対象になりません。
3. 非公開グループには **招待リンク** からのみ参加できます。招待リンクは有効期限、
   使用回数の上限、付与する権限（閲覧のみ／編集）を持ちます。
4. グループ所有者は構成員の権限を変更し、または除外できます。

## 3. 著作権と利用許諾

1. 利用者が作成した文書の著作権は **作成者に帰属します。**
2. 利用者は本サービスに対し、サービス提供に必要な範囲で当該文書を保存・複製・表示・
   送信する非独占的な利用を許諾します。
3. 公開グループに掲載する場合、他の利用者がその文書を読み、自身のウィキに統合し得る
   ことに同意するものとします。詳細は
   [共有・再利用および退会に関する同意](sharing-and-deletion.md) によります。
4. 利用者は文書ごとにリンク・引用・派生の可否を設定できます。文書ごとの設定は、
   所属グループの設定より **厳しくすることのみ可能** であり、緩めることはできません。

## 4. アップロードしてはならないもの

1. **原本ソースファイル** — PDF・表計算ファイルなど `raw/` に該当する原本ファイルは
   アップロード対象ではなく、クライアントがアップロード経路で遮断します。
2. 利用者に配布権限のない第三者著作物の全文または実質的部分。
3. 認証情報、接続情報、秘密鍵などのセキュリティ情報。ウィキ本文では
   `（接続情報は省略）` に置き換えてください。
4. 利用者が共有権限を持たない第三者の個人情報。
5. 法令に違反し、または他人の権利を侵害する内容。

## 5. 禁止行為

1. アクセス権限のないグループの文書にアクセスしようとする行為。
2. 招待リンクを権限のない第三者に頒布する行為。
3. 本サービスのアクセス制御・隔離規則を回避する行為。
4. 自動化された大量収集により本サービスの運営を妨害する行為。

## 6. 中断と利用終了

1. 運営者は保守・障害・法令遵守のために本サービスを一時中断することがあり、可能な
   場合は事前に告知します。
2. 利用者はいつでも退会できます。退会時のデータの取扱いは
   [共有・再利用および退会に関する同意](sharing-and-deletion.md) によります。
3. 第4条・第5条に重大な違反があった場合、運営者は利用を制限できます。

## 7. 免責

本サービスは、利用者が作成した文書の正確性を保証しません。文書は利用者と自動化ツールが
共同で作成するため、誤りや古い記述を含むことがあります。重要な判断にあたっては必ず
原典を確認してください。

## 8. 規約の変更

規約を変更する場合、施行日の少なくとも30日前に告知します。利用者に不利益な変更に
同意しない場合は退会できます。
