# 共有・再利用および退会に関する同意

- 文書バージョン: v1.0-draft
- 施行日: {{EFFECTIVE_DATE}}

> これは草案です。サービス開始前に法務レビューを受けてください。
> 本文書については登録時に個別の同意を取得します。

## 1. この文書が扱うこと

本サービスは知識を **参照** する道具ではなく **統合** する道具です。他人の文書を読み、
その内容を自分の文書に取り込んで書くことが通常の使い方です。そのため「共有」と「削除」
が一般的なファイル共有サービスとは異なる挙動になります。この違いを理解したうえで
同意してください。

## 2. 共有の意味

1. **公開グループ** に掲載した文書は、本サービスの他の利用者が閲覧できます。
2. 他の利用者は自分のウィキでその文書へリンクし、出典として引用できます。
3. 他の利用者はその内容を読み、**自分の文書を新たに作成** できます。
4. **非公開グループ** の文書は構成員のみが閲覧でき、外部文書の参照対象にならず、
   外部のグラフに存在も表題も現れません。

## 3. 取り消せない部分 — 必ずご確認ください

**他の利用者があなたの文書を読み、自分のウィキに統合して書いた文章は、あなたが文書を
削除しても、退会しても消えません。**

その文章は既にその人の著作物であり、本サービスはそれを回収する手段を持ちません。
回収を前提とした削除は約束しません。取り消せない公開を望まない内容は、
**最初から非公開グループに置くか、文書ごとの派生許可をオフにしてください。**

## 4. 文書ごとの設定

文書ごとに次を個別に設定できます。

| 設定 | 意味 |
|---|---|
| `links` | 他の文書がこの文書へリンクできるか |
| `citation` | 他の文書がこの文書を出典として引用できるか |
| `derivation` | 他の利用者がこの内容を自分の文書に統合できるか |
| `backlink` | この文書を指す被リンクを他の利用者に見せるか |

文書ごとの設定は、所属グループの設定より **厳しくすることのみ可能で、緩めることは
できません。** 非公開グループの文書を文書設定だけで公開することはできません。

## 5. 原本ソース（raw）の取扱い

1. **PDF・表計算ファイルなどの原本ファイルは本サービスにアップロードされません。**
   クライアントがアップロード経路で遮断します。
2. 共有時、原本ファイル名（`raw_ref`）と原文スナップショット
   （`source_snapshot.text`）はペイロードから除去するか、ハッシュに置き換えられます。
3. ただし、**利用者がウィキ本文に書き写した抜粋や要約は文書本文そのものであり、
   共有の対象です。** 原本ファイルをアップロードしないことと、原文から書き写した
   文章が共有されないことは別の話です。

## 6. 退会時の選択

退会時に次のいずれかを選択します。

**A. 全件削除**
- あなたが作成者である文書とブロックを削除します。
- 削除された文書の位置には、個人情報を含まない **削除標識（tombstone）** のみが
  残ります。これは他の利用者の文書における切れたリンクが「存在しない文書」ではなく
  「削除された文書」として表示されるようにするためのものです。
- 共同編集の文書では、あなたが作成したブロックのみが削除され、文書自体は残ります。

**B. 所有権を移転して保持**
- 文書の所有権を所属グループに移し、内容を保持します。
- 作成者表示は匿名の識別子に置き換えることができます。

## 7. 削除しても残るもの

全件削除を選択しても、次は残ります。

1. 他の利用者があなたの文書を読んで作成した **派生文書**
2. 削除標識（tombstone） — 文書識別子と削除時刻のみを含みます
3. 法令上の保存義務がある最小限の処理記録
4. 他の利用者のローカルキャッシュおよび既に配布された複製 — 同期の都度順次削除
   されますが、即時性は保証されません

## 8. 同意の確認

登録時に次の各項目への同意が必要です。

- [ ] 公開グループに掲載した文書を他の利用者が読み、引用し得ることを理解します。
- [ ] **他の利用者が統合して書いた派生文章は、私が退会しても消えない** ことを
      理解します。
- [ ] 原本ファイルはアップロードされないが、私がウィキ本文に書き写した内容は共有の
      対象であることを理解します。
- [ ] 第三者著作物の全文およびセキュリティ情報をアップロードしません。
