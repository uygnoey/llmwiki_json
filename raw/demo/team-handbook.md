# Team Handbook v2

A short reference for how the Alpha and Beta workstreams run day to day.

## Review

Every change is reviewed by one person who did not write it. A review that
finds nothing is still recorded, so the trail is complete either way.

## Releases

Releases go out on Thursdays. A release note names the change, the reviewer
and the rollback step. See [[release-process]] and [[review-policy]].
